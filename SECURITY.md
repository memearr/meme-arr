# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

1. Go to the repository's **Security** tab and choose **Report a vulnerability**
   (https://github.com/memearr/meme-arr/security/advisories/new).
2. Include the version (shown in the app's sidebar), what you found, and the steps to
   reproduce it.

This is a volunteer project, so replies are best effort, but reports are taken seriously and
a fix is released as soon as it can be verified.

## Supported versions

Only the latest release receives security fixes. Upgrading is a pull of the new image; see
[Upgrading](docs/UPGRADING.md).

## How the app is meant to be run

meme-arr is built for a home network. What it protects, what it stores, and how to expose it
safely are described in [docs/SECURITY.md](docs/SECURITY.md).
